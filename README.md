### 🚀 About Me

I'm a **Software Developer** based in **Ahmedabad, Gujarat, India**, working across the full stack — Next.js + TypeScript on the front, Node/Django services and Postgres on the back, and the LLM calls in between.

I founded and built **TalentMesh**, a multi-portal AI recruitment SaaS for the Indian market (separate Admin, Recruiter, and Candidate portals), and have been running and shipping it since **January 2026**. I also built **DisneyShield.AI**, an AI pipeline that detects pirated content and automates DMCA takedowns.

Most of my work ends up in production: routing AI requests through **OpenRouter** to keep cost and latency down, wiring **Razorpay** subscriptions with webhook handling, enforcing **Postgres RLS** for tenant isolation, and putting **RBAC, session guards, and audit logs** in front of it. I use AI coding agents (**Claude Code**, **Cursor**) daily and write the `CLAUDE.md` / `AGENTS.md` rule files that keep them consistent with the architecture.

I care about output quality — noisy AI results lose user trust faster than a missing feature does.

<br/>

**🔭 Currently**
- Shipping TalentMesh v1 as the lead developer: candidate matching, resume parsing, and payments.
- Writing and maintaining the agent instruction files that drive our AI coding workflow.
- Taking on freelance/contract web + AI work in parallel.

**🛠️ How I work**
- Ship features end to end — UI, API routes, database schema, and the LLM calls behind them.
- Prefer boring, auditable infrastructure (Postgres RLS, JWT + sessions, audit logs) over clever abstractions.
- Write the docs, then the code — onboarding, compliance, and API docs are part of the feature.
