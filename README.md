## 🧠 What I've Learned Shipping

- **Tenant isolation is a database problem.** App-level checks are not enough — Postgres RLS is the actual boundary.
- **Route models by task, not by habit.** OpenRouter with per-task routing keeps cost and latency predictable.
- **Agent instruction files are code.** `CLAUDE.md` and `AGENTS.md` need reviews like any other source file, or agents drift.
- **Audit your own auth.** I found ID mismatches and isolation gaps only by re-reading my own code with fresh eyes.
- **Noisy AI output loses trust faster than a missing feature.** Quality of the answer is the product.
